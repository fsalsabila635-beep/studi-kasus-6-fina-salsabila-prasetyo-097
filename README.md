# penjelasan program

Sistem Pencatatan Nilai Mahasiswa merupakan program sederhan yang digunakan untuk mencatat dan melihat riwayat nilai mahasiswa. Program ini menggunakan file JSON sebagai media penyimpanan data dan data yang telah dimasukkan akan disimpan ke dalam file data_nilai.json, sehingga data tidak akan hilang meskipun program ditutup dan dijalankan kembali.

Program ini juga memiliki beberapa fitur utama, yaitu:

- Melihat seluruh data nilai mahasiswa.

- Menambahkan data nilai mahasiswa baru.

- Menyimpan data secara permanen ke dalam file JSON.

- Menjalankan program secara terus-menerus menggunakan while loop.

- Menghentikan program ketika pengguna memilih menu keluar.
